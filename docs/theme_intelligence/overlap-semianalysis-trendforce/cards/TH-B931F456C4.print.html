01 BOTTOM LINE

SOURCE OPINIONThe article argues sparse attention reduces KV cache memory and bandwidth at the SDPA operation but does not reduce overall memory capacity usage, because top-k selection requires the full context in HBM, and system optimizations like HiSparse offload KV cache to host DRAM rather than eliminating it. C-9f3d0dc68a6fd5 C-293bc78c1049d2
SOURCE OPINIONThe article frames the question as how sparse attention affects memory TAM including HBM and NAND, and concludes the sparse attention memory profile alone cannot portray KV cache efficiency; system optimizations keep memory capacity in play and shift reuse to host DRAM. C-9f3d0dc68a6fd5 C-293bc78c1049d2 C-6be84c324e943f
MODEL INFERENCEIf sparse attention does not shrink memory capacity needs and instead shifts reuse to host DRAM, demand for HBM, DRAM and NAND in AI serving infrastructure is unlikely to be eroded by this efficiency technique, supporting the memory TAM.
