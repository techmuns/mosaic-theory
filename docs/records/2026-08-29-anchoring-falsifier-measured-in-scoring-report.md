# Anchoring falsifier, measured (`vinci/scoring/metrics.py::override_rate` + report block) — the accepted risk gets its numbers

**WHAT.** The scoring report (`ScoreReport.to_markdown` — the artifact BOTH default paths emit:
`vinci score` and `run_monthly`'s committed `scoring_report.md`) gains one block under the
machine-proposal shadow curves: the pivot's recorded anchoring falsifier, quoted, with the two
quantities it names computed beside it — **override rate** = overridden ÷ (confirmed + overridden)
over resolved proposal-bearing rows, and **human−machine spread delta** = `buy_avoid_spread −
machine_buy_avoid_spread` (same resolved screen-origin set, comparable by construction). One pure
helper (`vinci/scoring/metrics.py::override_rate`) + render lines; no new fields, no new inputs.

**Measured, never adjudicated:** no threshold constant, no verdict line, and no parameter anywhere
reads these numbers back — the ~0 / within-noise reading stays the operator's. An empty
denominator prints `insufficient rows (n=0 proposal-bearing resolved)` — never 0.0, because a
fabricated 0.0 reads as exactly the collapse the falsifier watches for. A missing curve prints
`UNDEFINED` naming WHICH curve (human / machine / both). The rate is CUMULATIVE since the pivot:
`VerdictScore` carries no dates, so a trailing window was consciously NOT built (it would widen
the diff into the harness for a quantity the falsifier states cumulatively).

**WHY.** CLAUDE.md records the pivot's accepted risk WITH its falsifier ("a machine proposal
ANCHORS the human — if the override rate collapses toward ~0 or the human spread tracks the
machine spread within noise → revisit verdict placement") and nothing computed either quantity —
the operator eyeballed raw disposition counts. That is the recorded-criterion-nobody-measures
class: SMPL's OWYN kill criterion printed on every monitor run while nobody computed OWYN net
sales, and the deterioration was caught by a re-assembly instead
(`docs/records/2026-08-27-between-print-monitor-panels.md`). The invariant rule says an accepted
risk ships a machine check or stays consciously accepted — this ships the measurement half; the
conclusion half stays human by design.

**Origin:** Item 3 of the theme-thesis-card brief — the port analysis of the operator's
predecessor chat framework (Thematic Book Construction Checklist v6.2.1, `~/Downloads/files.zip`),
whose OL10 override-escalation ladder was the ported idea, reduced here to measurement-only to
respect the machine-surfaces/human-concludes line.
